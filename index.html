01 / Platform

Home Assistant

EV Smart Charger runs as a custom Home Assistant integration. Install from the built-in Marketplace on Home Assistant 2026.11 or later, or through HACS on older versions.

02 / Hardware

Charger controls and sensors

Your wallbox must expose a charging-current control in Home Assistant. You’ll also need energy and battery sensors. Check the entity list.

03 / Interface

Dashboard optional

Use the integration without a dashboard, add the included card manually, or have an administrator explicitly create a dashboard.

02 / Quick start

From install to first charge.

  1. Step 01

    Find EV Smart Charger

    On Home Assistant 2026.11 and later, open Settings → Marketplace. On older versions, open HACS. Search for EV Smart Charger.

  2. Step 02

    Install your way

    In Marketplace, choose Install to start setup. In HACS, download it, restart Home Assistant, then add EV Smart Charger under Settings → Devices & services.

  3. Step 03

    Connect your equipment

    Follow the prompts to map your wallbox and energy sensors. You can opt in to the dashboard during setup or build it later.

03 / Help

Good to know.

Will this change my existing dashboards?

No. The builder is optional and only creates a new dashboard after an administrator explicitly confirms. See the dashboard builder guide.

Does the simulator connect to my charger?

No. It uses example values only and does not connect to Home Assistant or send commands to your charger.

Where do I report an issue?

Check the project documentation first. If the issue persists, visit GitHub Issues.
